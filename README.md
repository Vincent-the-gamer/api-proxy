# api-proxy

Proxy behind some webpage APIs, used for add headers which banned by browsers, like Referer, etc.

## Link

https://api-proxy.vince-g.xyz

## APIs

```json
{
    "type": "score",
    "state": "月饼里面，我最喜欢冰淇淋的，其次喜欢蛋黄的，不过也没觉得好吃",

    "options": [
        "冰淇淋",
        "蛋黄",
        "火腿"
    ]
}
```
